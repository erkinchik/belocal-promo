# BeLocal Promo Site

A beautiful one-page announcement website for belocal.world, built with Next.js and Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Modern, clean design inspired by travel websites
- Fully responsive layout
- Beautiful hero section with gradient background
- Feature showcase section
- Email subscription form
- Professional footer

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
